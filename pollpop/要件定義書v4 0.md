# リアルタイム5択投票SaaS「PollPop」要件定義書 v4.0 (確定版)

## 1. プロダクト概要 & ビジョン

- **プロダクト名:** PollPop（ポールポップ）
- **ターゲット:** 英語圏（Global）のYouTube / Twitch ストリーマー、VTuber、オンラインコミュニティ
- **コンセプト:** 「5秒作成・5択特化・爆速アニメーション・ライブ演出」を提供するストリーマー向けリアルタイム投票 ＆ エンタメ収益化SaaS
- **コア体験:** 5秒で作成 \rightarrow 視聴者がスマホで連打投票（または有料票購入） \rightarrow OBS画面上で動物が爆走・ジャンプ・金貨バーストする爆速体験（遅延0.5秒未満）

## 3. 連打（Combo）＆ 有料票（Super Vote）システム

### 3.1 無料連打（Votes Per Voter）

- **1人あたり上限票数設定:** Poll作成時に設定可能（`1票`, `3票`, `5票`, `10票`, `12票`, `Unlimited` / デフォルト: `5票`）。
- **Voter UI (スマホ画面):** 残り票数を表示（`Remaining: 3 / 5`）。連打時に **`2 COMBO!` `3 COMBO!`** の演出。`localStorage` で投じた票数を保持。

### 3.2 有料票（Super Votes - v4.0拡張機能）

- **コンセプト:** 「Pay to Win（課金して推しを勝たせる）」。無料票を使い切った後、または最初から一気に票をぶち込める機能。
- **購入メニュー例:**
    - **$1.99:** ＋50票 ＋ ミニバースト演出
    - **$4.99:** ＋200票 ＋ サポーター名表示 ＋ 中バースト演出
    - **$9.99:** ＋500票 ＋ **画面全体に金貨の雨（Golden Bomb） ＋ 動物ジェット噴射超加速**
- **Stripe Connect連携:** 視聴者が決済した金額からプラットフォーム手数料（約15%）を引いた額が、配信者のStripe口座へ直接自動振込。

## 5. データベース設計（Supabase / Firebase 共通概念）

### 5.1 Supabase PostgreSQL スキーマ

```
-- 1. Profiles Table (Stripeサブスク & Connect管理)
create table public.profiles (
  id uuid references auth.users(id) on delete cascade primary key,
  stripe_customer_id text,
  stripe_subscription_id text,
  stripe_connect_account_id text, -- 有料票受け取り用アカウントID
  is_pro boolean default false,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Polls Table
create table public.polls (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id) on delete cascade, -- null = guest creator
  title text not null,
  options jsonb not null, -- [{"id": 1, "text": "Opt A"}, ...]
  theme text default 'animal_race', -- 'animal_race', 'gacha', 'neon_rgb'
  max_votes_per_user integer default 5, -- 1, 3, 5, 10, 12, -1 (Unlimited)
  is_closed boolean default false,

  -- Pro / Super Votes Settings
  enable_super_votes boolean default false, -- 有料票機能ON/OFF
  manual_votes jsonb default '{}'::jsonb, -- 有料票・手動加算分 {"1": 500, "2": 0}
  custom_mascot_url text, -- Pro: 配信者オリジナル走る画像

  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Votes Table (無料票ログ)
create table public.votes (
  id uuid default gen_random_uuid() primary key,
  poll_id uuid references public.polls(id) on delete cascade not null,
  option_id integer not null,
  voter_fingerprint text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 4. Paid Votes Transactions Table (有料票取引ログ)
create table public.paid_votes (
  id uuid default gen_random_uuid() primary key,
  poll_id uuid references public.polls(id) on delete cascade not null,
  option_id integer not null,
  vote_count integer not null, -- 例: 500票
  amount_cents integer not null, -- 例: 999 ($9.99)
  supporter_name text default 'Anonymous',
  stripe_payment_intent_id text unique,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- RLS Enable & Policies
alter table public.profiles enable row level security;
alter table public.polls enable row level security;
alter table public.votes enable row level security;
alter table public.paid_votes enable row level security;

create policy "Allow public read polls" on public.polls for select using (true);
create policy "Allow insert polls" on public.polls for insert with check (true);
create policy "Allow public insert votes" on public.votes for insert with check (true);

-- Realtime WebSockets Enable
alter publication supabase_realtime add table public.polls;
alter publication supabase_realtime add table public.votes;
alter publication supabase_realtime add table public.paid_votes;
```
