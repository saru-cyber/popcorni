# PollPop - Development Rules v4.0

## Product Vision & Monetization
- Real-time 5-option interactive polling SaaS for global Twitch/YouTube streamers.
- Primary Language: English (Default UI).
- Free Tier ($0): 1 active poll at a time, web results + FREE "Animal Race Mode" overlay (animals running at the tip of the bars).
- Pro Tier ($8/mo or $80/yr via Stripe): Unlocks 1% Critical Big Mark Gacha FX, Custom Mascot Avatars running, RGB Rainbow 1st Place, multiple active polls, and Google Sheets sync.
- Future Expansion (Paid Votes): Streamers receive tips ($1.99 - $9.99 for +500 votes + Golden Coin FX) via Stripe Connect.

## Combo System & Limits
- Support "Votes Per Person" limit: 1, 3, 5, 10, 12, or Unlimited (Default: 5).
- Track voter cast count in localStorage (`voted_count_[poll_id]`).
- Show "Remaining Votes" counter and trigger "Combo!" animation on rapid taps.

## Tech Stack
- Next.js 14+ (App Router, TypeScript)
- Tailwind CSS, shadcn/ui, Framer Motion
- Supabase (Realtime WebSockets) OR Firebase (Firestore with onSnapshot)
- Stripe (Subscriptions + Stripe Connect)

## Critical Coding Rules
1. Free Tier Constraint: Store `active_poll_id` in localStorage for guests. Block creating new polls if an unclosed poll exists, and redirect them to `/poll/[id]/admin`.
2. Animal Race UI (`/poll/[id]/obs`):
   - Bars styled like race tracks with `bg-transparent`.
   - Running animal icons (Dog, Cat, Rabbit, Penguin, etc.) attached at the tip of each bar.
   - On vote event: Trigger Framer Motion `scale(1.4)` dash/jump animation.
   - On Paid Vote event: Trigger Super-Saiyan/Rocket Boost FX + Golden Coin Rain.
